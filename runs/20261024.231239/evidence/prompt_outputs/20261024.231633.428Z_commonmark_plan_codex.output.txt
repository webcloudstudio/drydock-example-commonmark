# FEATURE: Raw HTML

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Preserves inline raw HTML tags and markup in rendered output. |
| Depends On  | ARCHITECTURE.md |
| Provides    | inline raw HTML |
| Consumes    | — |

## Questions

- None.

## Purpose

Preserve valid inline HTML tags, comments, processing instructions, declarations, and CDATA sections as literal markup in HTML output.

## Behavior

- Recognize the raw HTML forms defined by CommonMark 0.31.2 within inline content.
- Preserve recognized markup verbatim, including tag names, attributes, whitespace, and line breaks.
- Escape `<` and `>` when the input resembles markup but does not match a recognized raw HTML form.
- Block HTML parsing is owned by `FEATURE-HTML-BLOCKS.md`.

# FEATURE: Hard Line Breaks

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Parses hard line breaks within inline content. |
| Depends On  | ARCHITECTURE.md |
| Provides    | hard line breaks |
| Consumes    | — |

## Questions

- None.

## Behavior

- Render a line ending preceded by at least two spaces as `<br />` when it occurs within a block.
- Render a backslash immediately before a line ending as `<br />` within a block.
- Ignore leading spaces on the following line after a hard break.
- Do not treat either form as a hard break at the end of a block or inside code spans or HTML tags.
