<requirement name="configure-test-runner" stories="">
Support command-line options for selecting the program, specification file, section pattern, dynamic library directory, normalization behavior, test dumping, normalization debugging, an individual example number, and change tracking.
</requirement>
<requirement name="parse-spec-examples" stories="">
Read the specification file, extract Markdown examples and expected HTML, and associate each test with its example number, source lines, and section.
</requirement>
<requirement name="run-and-compare-tests" stories="cli-001">
Run each selected Markdown example through the CommonMark program, compare its HTML output with expected HTML, and report failures or errors.
</requirement>
<requirement name="normalize-html" stories="">
Normalize actual and expected HTML before comparison, unless normalization is disabled.
</requirement>
<requirement name="dump-tests-as-json" stories="">
Dump the selected tests in JSON format.
</requirement>
<requirement name="debug-html-normalization" stories="">
Filter standard input through the HTML normalizer in debug-normalization mode.
</requirement>
<requirement name="track-test-result-changes" stories="">
Track test results in a JSON file and report only changes from previous results.
</requirement>
<requirement name="report-test-counts" stories="">
Report the counts of passed, failed, errored, and skipped tests, and exit with the sum of failures and errors.
</requirement>
