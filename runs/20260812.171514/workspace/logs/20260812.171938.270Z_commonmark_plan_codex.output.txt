# FEATURE: Block Quotes

| Field       | Value |
|-------------|-------|
| Version     | 20260812 V1 |
| Description | Defines nested CommonMark block quote parsing and lazy continuation behavior. |
| Depends On  | FEATURE-BLOCK-LEAF.md |
| Provides    | block quote parser |
| Consumes    | leaf block parser |

## Questions

- None.

## Behavior

The parser recognizes block quote markers with optional indentation and optional following whitespace. It supports nested block quotes, empty quotes, blank lines, quoted leaf blocks, and lazy continuation lines only when those lines continue paragraph content. Block quote boundaries remain distinct across blank lines.

- None.

## Guardrails

- Block structure is resolved before inline structure.
- Lazy continuation does not absorb lines that begin a new block construct.
- Public Markdown implementations are not used.

# FEATURE: Inline Escapes and Character References

| Field       | Value |
|-------------|-------|
| Version     | 20260812 V1 |
| Description | Defines CommonMark punctuation escapes and named and numeric character reference parsing. |
| Depends On  | FEATURE-BLOCK-LISTS.md |
| Provides    | escape parser, character reference parser |
| Consumes    | block parser |

## Questions

- None.

## Behavior

The inline parser recognizes backslash escapes for ASCII punctuation, valid HTML named entities, decimal references, and hexadecimal references. Invalid Unicode scalar values and U+0000 become U+FFFD. References are unavailable in code spans and code blocks and cannot substitute for block or inline structural markers.

The inline parser matches code span delimiters of equal length and normalizes line endings and paired boundary spaces according to CommonMark.
