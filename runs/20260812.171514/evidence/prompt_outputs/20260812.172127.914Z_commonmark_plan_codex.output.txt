# FEATURE: Inline Links and Images

| Field       | Value |
|-------------|-------|
| Version     | 20260812 V1 |
| Description | Parses inline links, reference links, and images according to CommonMark 0.31.2. |
| Depends On  | ARCHITECTURE.md, FEATURE-BLOCK-LISTS.md, FEATURE-INLINE-EMPHASIS.md |
| Provides    | link parser, image parser, reference resolver |
| Consumes    | block parser, inline parser |

## Questions

- None.

## Behavior

The parser recognizes inline links with optional destinations and titles, including balanced and escaped parentheses and angle-bracket destinations. It resolves full, collapsed, and shortcut reference links using case-folded labels and first-definition precedence. It parses nested image descriptions and renders image alt text from their plain content. Links cannot contain links, while image descriptions may contain links.

Destinations, titles, labels, and image attributes follow the escaping, entity, whitespace, and normalization rules defined by CommonMark 0.31.2.

|-------------|-------|
| Version     | 20260812 V1 |
| Description | Parses URI autolinks, email autolinks, and raw HTML according to CommonMark 0.31.2. |
| Depends On  | ARCHITECTURE.md, FEATURE-INLINE-LINKS.md |
| Provides    | autolink parser, raw HTML parser |
| Consumes    | block parser, inline parser |

## Questions

- None.

## Behavior

The parser recognizes absolute URI and email autolinks inside angle brackets. It preserves valid raw HTML tags, comments, declarations, processing instructions, and CDATA sections without interpreting their contents as Markdown inline syntax. Invalid tag-like text remains escaped text.

Autolinks apply the CommonMark scheme and email-address rules. Backslash escapes do not alter autolinks or raw HTML.

# FEATURE: Block HTML Rendering

| Field       | Value |
|-------------|-------|
| Version     | 20260812 V1 |
| Description | Renders parsed CommonMark block structure as conforming HTML. |
| Depends On  | ARCHITECTURE.md, FEATURE-INLINE-HTML.md |
| Provides    | block HTML renderer |
| Consumes    | block parser, inline parser |

## Questions

- None.

## Behavior

The renderer emits CommonMark HTML for headings, paragraphs, thematic breaks, indented and fenced code blocks, block quotes, link-reference-free content, and lists. It preserves block nesting, escapes literal block content, emits required trailing line endings, and applies tight or loose list paragraph rules.

Raw HTML blocks remain raw. Code blocks remain literal and do not receive inline parsing.

# FEATURE: Rendered URL and Attribute Normalization

| Field       | Value |
|-------------|-------|
| Version     | 20260812 V1 |
| Description | Produces normalized URLs, titles, attributes, and special-character output expected by the supplied harness. |
| Depends On  | ARCHITECTURE.md, FEATURE-RENDER-INLINE.md |
| Provides    | normalized URL output, normalized title output, normalized attribute output |
| Consumes    | block HTML renderer, inline HTML renderer |

## Questions

- None.

## Behavior

Rendered destinations percent-encode characters required by the conformance expectations while preserving existing URL escapes. Titles and attributes are escaped correctly, entity and numeric references resolve in permitted contexts, and significant HTML output remains compatible with the supplied normalizer.

The renderer does not use normalization output as its implementation oracle; the supplied normalizer is used only by the conformance harness.
