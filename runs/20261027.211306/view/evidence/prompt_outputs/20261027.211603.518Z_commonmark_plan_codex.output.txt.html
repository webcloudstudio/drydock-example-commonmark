# FEATURE: Links

| Field | Value |
|-------|-------|
| Version | 20261027 V1 |
| Description | Parse inline and reference links using the completed document reference map. |
| Depends On | FEATURE-Emphasis.md, FEATURE-ReferenceDefinitions.md |
| Provides | link parsing |
| Consumes | document reference map, inline text parsing, code span parsing, emphasis parsing |

## Questions

- None.

## Purpose and workflow

During the inline phase, recognize inline links and full, collapsed, and shortcut reference links. Resolve references against the completed document-wide map, using Unicode case folding and whitespace normalization for labels. The first matching definition wins.

Parse destinations and optional titles according to the specification, including balanced parentheses, angle-delimited destinations, escapes, character references, and the permitted whitespace. Apply the delimiter-stack link procedure: find the nearest active bracket opener, process emphasis within the link text, and deactivate earlier link openers after forming a link. Links cannot contain links. Code spans and other higher-precedence constructs retain their specified precedence.

For direct incremental acceptance, expose `parse_links(source, references)` from `commonmark_parser.links`. It returns a sequence of inline nodes. A link node exposes `type`, `destination`, `title`, and `children`; text nodes expose `type` and `literal`. The reference mapping uses normalized labels and values containing `destination` and `title`. This interface accepts already collected references and does not require later inline providers.

## Programmatic Acceptance

=== AC links-inline ===
Intent: Inline link parsing returns the supplied destination and title and retains the link text as children.

from commonmark_parser.links import parse_links

label = "label"
destination = "/destination"
title = "caption"
source = f'[{label}]({destination} "{title}")'
nodes = parse_links(source, {})
assert len(nodes) == 1
link = nodes[0]
assert link.type == "link"
assert link.destination == destination
assert link.title == title
assert len(link.children) == 1
assert link.children[0].type == "text"
assert link.children[0].literal == label
=== END AC links-inline ===

=== AC links-reference ===

from commonmark_parser.links import parse_links

label = "reference"
destination = "/target"

    assert len(nodes) == 1
    assert nodes[0].type == "link"
    assert nodes[0].destination == destination
    assert nodes[0].title is None

- None.

## Purpose and workflow

Recognize angle-delimited absolute URI autolinks with a scheme of two to 32 permitted ASCII characters and no forbidden URI characters. Recognize email autolinks using the specification's email grammar. The visible label is the enclosed text; an email destination adds the `mailto:` scheme. Backslash escapes do not operate inside an autolink. Encode destinations and escape HTML when rendering, and respect code-span precedence.

For direct incremental acceptance, expose `parse_autolinks(source)` from `commonmark_parser.autolinks`. It returns inline nodes. An autolink node exposes `type`, `destination`, and `label`; ordinary text nodes expose `type` and `literal`.

| Provides | inline HTML and hard break parsing |
| Consumes | inline text parsing, code span parsing |

## Questions

- None.

## Purpose and workflow

Recognize the specification's open and closing tags, comments, processing instructions, declarations, and CDATA sections as raw inline HTML. Preserve valid raw HTML verbatim, including attribute contents. Text that does not match the grammar remains ordinary text.

A line ending preceded by at least two spaces or an unescaped backslash forms a hard break within an inline block. Do not create hard breaks inside code spans or HTML tags, or at the end of a block.

For direct incremental acceptance, expose `parse_inline_html_breaks(source)` from `commonmark_parser.inline_html_breaks`. It returns inline nodes. Raw HTML nodes expose `type` and `literal`; hard breaks have type `hardbreak`; ordinary text nodes expose `type` and `literal`.

=== AC inline-hard-breaks ===
Intent: Both specified hard-break forms create a break between text, while a trailing backslash remains text.

from commonmark_parser.inline_html_breaks import parse_inline_html_breaks

for source in ("first  \nsecond", "first\\\nsecond"):
    nodes = parse_inline_html_breaks(source)
