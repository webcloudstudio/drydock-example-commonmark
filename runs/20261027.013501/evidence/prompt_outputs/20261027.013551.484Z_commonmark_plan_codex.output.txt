## story block_parsing
summary:      Parse CommonMark block structure and collect link reference definitions.
type:         service
kind:         capability
phase:        1
implements:   FEATURE-BlockParsing.md
covers:       BLOCK-001, BLOCK-002, BLOCK-003, BLOCK-004, BLOCK-005, BLOCK-006, BLOCK-007
context:      sources/spec.txt, sources/spec_tests.py, sources/cmark.py, sources/normalize.py
context_roles: |
  FEATURE-BlockParsing.md: capability specification
  sources/spec.txt: normative specification and conformance test suite
  sources/spec_tests.py: conformance test harness
  sources/cmark.py: reference implementation context
  sources/normalize.py: test helper
stack:        common.md, python.md
consumes:     commonmark executable
provides:     block parsing, link reference collection, block rendering
depends:      cli_entrypoint
acceptance:   yes
instructions: |
  Implement block parsing before inline parsing, using the supplied specification and its appendix
  parsing strategy. Process lines in sequence into block structure; preserve block boundaries,
  container nesting, literal code and raw HTML, and collect reference definitions document-wide
  before inline resolution. Implement thematic breaks, ATX and setext headings, paragraphs, blank
  lines, indented and fenced code, all seven HTML block types, link reference definitions, block
  quotes (including lazy continuation), and lists (including indentation, nesting, continuation,
  tightness, and ordered-list attributes). Blocks always take precedence over inline syntax.

## story inline_parsing
summary:      Parse inline content and render CommonMark HTML.
type:         service
kind:         capability
phase:        1
implements:   FEATURE-InlineParsing.md
covers:       INLINE-001, INLINE-002, INLINE-003, INLINE-004, INLINE-005, INLINE-006
context:      sources/spec.txt, sources/spec_tests.py, sources/cmark.py, sources/normalize.py
context_roles: |
  FEATURE-InlineParsing.md: capability specification
  sources/spec.txt: normative specification and conformance test suite
  sources/spec_tests.py: conformance test harness
  sources/cmark.py: reference implementation context
  sources/normalize.py: test helper
stack:        common.md, python.md
consumes:     block parsing, link reference collection
provides:     inline parsing, HTML rendering
depends:      block_parsing
acceptance:   yes
instructions: |
  Parse inline text only after block structure and document-wide link reference collection are
  complete. Implement escapes and character references; code spans and hard and soft breaks;
  emphasis delimiter runs and precedence; inline, reference, collapsed and shortcut links and
  images; autolinks; raw HTML; and remaining text. Preserve the supplied specification's
  precedence and rendering rules. Link reference matching uses normalized, case-folded labels and
  the first definition wins.
