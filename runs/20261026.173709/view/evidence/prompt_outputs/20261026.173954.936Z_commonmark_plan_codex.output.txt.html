# FEATURE: Code Spans

| Field       | Value |
|-------------|-------|
| Version     | 20261026 V1 |
| Description | Parses CommonMark code spans in inline content. |
| Depends On  | FEATURE-CommandLine.md |
| Provides    | code span parsing |
| Consumes    | commonmark executable |

## Questions

- None.

## Purpose

Parse inline code spans according to CommonMark 0.31.2. Code span parsing runs after block structure is resolved and before other inline formatting is applied.

## Behavior

- A backtick string is a run of one or more backticks not adjacent to another backtick.
- A code span opens with a backtick string and closes at the next backtick string of equal length. Unmatched runs remain literal text.
- Convert line endings inside the span to spaces. If the resulting content begins and ends with U+0020 and is not entirely spaces, remove exactly one space from each end.
- Preserve all other content literally, including backslashes, character references, and Markdown markers. Escape the resulting content for HTML inside `<code>`.

## Questions

- None.

## Purpose

Parse emphasis and strong emphasis according to the CommonMark 0.31.2 delimiter-run algorithm.

## Behavior

- Identify delimiter runs of `*` and `_`, and determine their left- and right-flanking status using Unicode whitespace and punctuation.
- Apply the distinct opening and closing rules for `*` and `_`, including the restriction on intraword underscore emphasis.
- Match delimiters according to the rule of three, consume one delimiter for emphasis or two for strong emphasis, and leave unused delimiters as literal text.
- Resolve nesting and overlapping spans according to the specification’s ambiguity rules. Code spans, links, images, and HTML tags bind more tightly than emphasis.

# FEATURE: Line Breaks

| Field       | Value |

| Description | Parses CommonMark hard and soft line breaks. |
| Depends On  | FEATURE-CommandLine.md |
| Provides    | hard and soft line break parsing |
| Consumes     | commonmark executable |

## Questions

- None.

## Purpose

Parse hard and soft line breaks in inline content according to CommonMark 0.31.2.

## Behavior

- A line ending preceded by two or more spaces or by a backslash is a hard line break when it occurs within a block, not at the block’s end.
- After a hard break, ignore leading spaces on the following line.
- A regular line ending is a soft break; rendering it as a line ending is conforming.
- Remove spaces at line edges as specified. Do not treat line breaks inside code spans or HTML tags as inline breaks.
