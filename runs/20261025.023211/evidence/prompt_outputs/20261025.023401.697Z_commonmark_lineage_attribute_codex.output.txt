<requirement name="parse-into-ast" stories="block_parsing,inline_parsing">

representation of the syntax tree instead of HTML.
</requirement>
<requirement name="html-rendering" stories="inline_parsing">

to make, and the choice of HTML for the tests makes it possible to run the
tests against an implementation without writing an abstract syntax tree renderer.
</requirement>
