# ARCHITECTURE: CommonMark Parser

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Defines the self-contained Python parser structure and command-line rendering flow. |
| Provides    | commonmark parser package structure |

## Questions

- None.

## Purpose

Provide the Python project foundation for a command-line parser that converts Markdown to HTML. The parser is implemented in this project; it must not depend on a public Markdown implementation.

## Modules and flow

The parser processes a document in two phases:

1. The block parser identifies document structure and collects link reference definitions across the whole document.
2. The inline parser processes paragraph and heading content using that completed reference map. The renderer emits HTML for the resulting structure.

The `commonmark` executable reads UTF-8 Markdown from standard input, invokes the parser, and writes HTML to standard output.

## Module ownership

| Boundary | Owner | Responsibility |
|---|---|---|
| Block parsing | Block parser | Parse block structure and collect document-wide references. |
| Inline parsing | Inline parser | Parse inline syntax and resolve links using the reference map. |
| HTML rendering | Renderer | Convert parsed blocks and inlines to HTML. |
| Command-line interface | `commonmark` executable | Connect standard input and standard output to the parser. |
| Persistence, configuration, file store, external services | None | The parser has no persistent state or external service boundary. |

## Technology Stack

- Python 3 implements the parser and executable.
- Python standard library provides runtime support; no third-party runtime dependency is required.
- POSIX shell is used by the supplied conformance entry point.

# FEATURE: Block Parsing

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Parses CommonMark block structure and collects document-wide link reference definitions. |
| Depends On  | ARCHITECTURE.md |
| Provides    | block parser, document reference map |

## Questions

- None.

## Purpose

Given Markdown lines, identify blocks before inline parsing. Collect valid link reference definitions during block parsing so links can resolve anywhere in the document, including definitions inside containers.

## Behavior

Implement the block constructs defined by the CommonMark 0.31.2 specification: thematic breaks; ATX and setext headings; indented and fenced code blocks; HTML blocks; paragraphs and blank lines; block quotes, including lazy continuation; and lists, including nesting, continuation, empty items, and tight or loose rendering.

Block structure takes precedence over inline syntax. Parse and render the complete behavior in the assigned source sections, preserving literal code-block contents and raw HTML behavior. Reference definitions are document-wide, first-definition-wins, and do not render as visible blocks.

# FEATURE: Inline Parsing

| Field       | Value |
|-------------|-------|
| Version     | 20261025 V1 |
| Description | Parses CommonMark inline syntax and renders inline HTML. |
| Depends On  | ARCHITECTURE.md, FEATURE-Block-Parsing.md |
| Provides    | inline parser, HTML renderer |
| Consumes    | block parser, document reference map |

## Questions

- None.

## Purpose

Parse inline content after block structure and document-wide link reference definitions are available. Render the parsed inline elements as HTML.

## Behavior

Implement the CommonMark 0.31.2 inline constructs: escaped text; entity and numeric references; code spans; delimiter-based emphasis and strong emphasis; inline and reference links; images; URI and email autolinks; raw HTML; hard and soft line breaks; and ordinary textual content.

Apply the specification's precedence and delimiter rules, including link and image nesting restrictions, reference-label normalization, URL and title parsing, and code-span normalization. Preserve raw HTML and escape ordinary text and attribute values as required by the specification examples.

# FEATURE: Executable

| Provides    | commonmark |
| Consumes    | block parser, inline parser |

## Questions

- None.

## Purpose

Provide an executable named `commonmark` at the application root. It reads UTF-8 Markdown from standard input and writes converted HTML to standard output.

## Behavior

On successful conversion, exit with status zero. On input or execution errors, exit nonzero and report the error on standard error. The supplied harness invokes the executable from the application root.

## Programmatic Acceptance

=== AC executable-stdin-stdout ===
Intent: The root executable accepts Markdown on standard input and emits converted output on standard output.

    capture_output=True,
    text=True,
    encoding="utf-8",
)
print(result.stderr)

assert result.stdout
